# Rise Task — Daily To-Do List

Prototype aplikasi to-do list responsif berdasarkan brief Mission.

## Fitur
- Profil pengguna yang dapat diedit.
- Hari, tanggal, dan jam real-time.
- Menambahkan tugas dengan prioritas Low, Medium, atau High.
- Kolom To Do dan Done dengan checkbox.
- Menghapus satu tugas atau seluruh tugas.
- Penyimpanan tugas dan profil di localStorage.
- Layout responsif untuk perangkat mobile.
- Animasi halus saat kartu tugas muncul.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser atau jalankan dengan ekstensi Live Server di VS Code.
3. Data disimpan pada browser yang sama melalui `localStorage`.

Nama dan jabatan awal merupakan contoh; ubah melalui tombol **Edit profil**.
